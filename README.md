## 🌟 What Is openevv?

openevv is a free, modern text-to-speech (TTS) program that brings the legendary voices of IBM's Embedded ViaVoice and ETI Eloquence back to life. If you remember the robotic but incredibly clear voices from old screen readers, or if you simply want a fast, lightweight TTS tool for your Windows computer, openevv is for you.

This program was carefully rebuilt using portable C code, which means it runs efficiently on today's hardware while preserving the authentic sound quality that made these classic engines famous. It's perfect for accessibility users, retro tech enthusiasts, or anyone who needs a reliable screen reader companion.
